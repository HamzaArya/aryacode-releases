# Arya Code 2.0.0

Created and maintained by **Hamza Arya**. Copyright © 2026 Hamza Arya.

This repository contains desktop release assets, checksums, release notes, and Arya Code build helpers. Application source is maintained separately.

**Arya Code 2.0.0 is available for macOS and Windows.** Download the verified packages below, or read the [2.0.0 release notes](https://github.com/HamzaArya/aryacode-releases/releases/tag/v2.0.0).

| Platform | Requirements | Download | Signing |
| --- | --- | --- | --- |
| macOS | Apple silicon, macOS 26 or newer | [Download DMG](https://github.com/HamzaArya/aryacode-releases/releases/download/v2.0.0/AryaCode-2.0.0-macOS-arm64.dmg) | Ad-hoc signed; not notarized |
| Windows | Windows x64 | [Download portable ZIP](https://github.com/HamzaArya/aryacode-releases/releases/download/v2.0.0/AryaCode-2.0.0-Windows-x64.zip) | Unsigned |

For Windows, extract the complete ZIP and launch `AryaCode.exe`. Install the native Arya SDK separately to use native Arya compiler and language services on Windows.
